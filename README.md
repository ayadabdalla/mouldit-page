# MouldIt project page

Source of the project page for
[MouldIt: Data Efficiency of Multi-Task Temporal Representation Learning in Injection Moulding](https://arxiv.org/abs/2611.13646).
Code: [ayadabdalla/mouldit_benchmark](https://github.com/ayadabdalla/mouldit_benchmark).

`index.html` is built from `src/page.html` by

```bash
PYTHONPATH=<path to mouldit_benchmark>/src python build.py
```

which draws the header curves from the real reference cycle.
